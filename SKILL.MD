# Token Efficient Coding

1. Inspect only files relevant to the requested task.
2. Never read the entire repository unless necessary.
3. Reuse existing project architecture and components.
4. Avoid repeating information already present in AGENTS.md.
5. Make focused changes instead of rewriting entire files.
6. Avoid unnecessary explanations and summaries.
7. Do not run repeated commands without a reason.
8. Run only relevant tests and analysis.
9. Do not redesign existing UI unless requested.
10. Ask before making destructive changes.

Response format:
- Changes made
- Files affected
- Tests performed
- Remaining issues

Keep responses concise.
